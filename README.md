# AI Practice Lab

A personal repo for studying AI with real model APIs. Each folder is an independent subproject.

## Subprojects

- [email-classifier/](email-classifier/): classifies support emails for an online sneaker store into categories and writes a short summary, using Google Gemini with structured output.
- [essay-draft-critique-rewrite/](essay-draft-critique-rewrite/): a three-step workflow where Gemini writes an essay draft, critiques it, and rewrites it. The final essay is shortened to 500 words or fewer if needed.
- [exchange-mcp-agent/](exchange-mcp-agent/): an agent that connects to a currency exchange MCP server, lets Gemini call its tools (such as `convert_currency`), and prints the conversation.

Each subproject has its own README with setup and run instructions.
